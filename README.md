# Економічна безпека країни: Малайзія

Вебсайт з аналізом економічної безпеки **Малайзії** за 2015–2024 рр. Виконано як практичну частину іспиту з дисципліни «Інформаційні технології у системі забезпечення економічної безпеки держави» (ДТЕУ).

**Автор:** Чайка Максим Володимирович, група ФІТ 2-7м
**Сайт:** [chayka1.github.io/Economic-security-Malaysia](https://chayka1.github.io/Economic-security-Malaysia/)

## Зміст сайту

| Сторінка | Що містить |
|---|---|
| `index.html`, **Головна** | Інформація про автора: ПІБ, освіта, наукові інтереси, контакти, коротко про проєкт |

## Як це працює

### 1. Дані
Вихідні дані взято з бази **World Bank, World Development Indicators** (Малайзія, код MYS) і записано в об'єкт `RAW` на початку файлу `script.js`:

| Показник | Код World Bank |
|---|---|
| Урожайність зернових, кг/га | AG.YLD.CREL.KG |
| Очікувана тривалість життя, жінки / чоловіки | SP.DYN.LE00.FE.IN / SP.DYN.LE00.MA.IN |
| Смертність немовлят, дівчатка / хлопчики | SP.DYN.IMRT.FE.IN / SP.DYN.IMRT.MA.IN |
| Експорт / імпорт товарів і послуг, % ВВП | NE.EXP.GNFS.ZS / NE.IMP.GNFS.ZS |
| Витрати на дослідження та розробки, % ВВП | GB.XPD.RSDV.GD.ZS |
| Частка доходів 10 % найбагатших / найбідніших | SI.DST.10TH.10 / SI.DST.FRST.10 |
| Борг центрального уряду, % ВВП | GC.DOD.TOTL.GD.ZS |

Якщо за рік немає даних, у масиві стоїть `null`, а в таблиці показано «–».

### 2. Розрахунки (`script.js`)
```js
cereal = кг/га ÷ 100                      // урожайність у ц/га
cover  = експорт ÷ імпорт                 // коефіцієнт покриття імпорту експортом
decile = частка 10 % багатих ÷ частка 10 % бідних   // співвідношення доходів
avg()  = середнє значення за роки з даними (null не враховується)
```

### 3. Визначення рівня безпеки
Для кожного показника задано порогові інтервали (`bands`) за методичними матеріалами. Функція `levelOf(значення, bands)` знаходить, у який інтервал потрапляє середнє значення, і повертає рівень: оптимальний, задовільний, незадовільний, небезпечний, критичний або абсолютна небезпека. Межі інтервалів враховано точно, тобто з урахуванням того, чи вони включні `[ ]` або виключні `( )`.

### 4. Побудова сторінки
Функція `buildAnalysis()` автоматично:
- заповнює зведену таблицю та смугу розподілу показників за рівнями;
- створює картку для кожного показника: графік, середнє значення, інтервал, висновок і таблицю «вихідні дані та розрахунки»;
- формує список джерел із посиланнями на World Bank.

### 5. Графіки
Графіки побудовано бібліотекою **[Chart.js](https://www.chartjs.org/)** (підключена з CDN cdnjs). Власний плагін `bandsPlugin` зафарбовує фон графіка кольоровими зонами порогових значень. Пунктирна лінія показує середнє за період, а підказка при наведенні — значення і рівень безпеки за конкретний рік.

### 6. Дизайн і адаптивність
`style.css` реалізує мінімалістичний стиль у дусі Apple: системний шрифт San Francisco, білий і світло-сірий фон, напівпрозоре меню з розмиттям, великі заголовки, картки із заокругленими кутами. Сітка (CSS Grid) перебудовується під планшет і телефон, широкі таблиці на малому екрані прокручуються горизонтально. Блоки плавно з'являються під час прокручування (`IntersectionObserver`).

## Як запустити локально
1. Завантажте репозиторій: **Code → Download ZIP** і розпакуйте архів.
2. Відкрийте `index.html` у браузері (подвійний клік).

Для графіків потрібен Інтернет, бо Chart.js завантажується з CDN.

## Як опублікувати на GitHub Pages
1. Створіть публічний репозиторій `Economic-security-Malaysia`.
2. **Add file → Upload files**: перетягніть `index.html`, `analysis.html`, `style.css`, `script.js`, `README.md` і натисніть **Commit changes**.
3. **Settings → Pages → Build and deployment**: Source — *Deploy from a branch*, Branch — `main`, папка `/ (root)`, потім **Save**.
4. Через 1–2 хвилини сайт буде доступний за адресою [chayka1.github.io/Economic-security-Malaysia](https://chayka1.github.io/Economic-security-Malaysia/).

## Як оновити дані
1. Завантажте нові значення з [data.worldbank.org](https://data.worldbank.org/) (Download → CSV/Excel).
2. Замініть числа в об'єкті `RAW` у `script.js`.
3. Середні значення, рівні безпеки, таблиці й графіки перерахуються автоматично. Тексти висновків в `analysis.html` і в полі `text` кожного показника оновіть вручну.
